# English / Swahili Conversational Example

## Input

Customer:
"Nimejaribu kulipa lakini bado inaonyesha sijalipa."

## Intent

payment_status

## Appropriate Response

"Pole kwa usumbufu. Tunaweza kuangalia hali ya malipo yako.
Tafadhali thibitisha namba ya simu uliyotumia kufanya malipo."

## Design Considerations

- Natural Kenyan Swahili
- Concise sentence structure
- Avoid unnecessary technical language
- Ask only for information necessary to proceed
- Do not imply successful payment verification without backend confirmation
