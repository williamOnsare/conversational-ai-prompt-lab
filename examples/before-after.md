# Prompt Refinement Example

## Before

You are a helpful customer support assistant.
Answer the customer politely and accurately.

## Problems

- Ambiguous objective
- No trusted-context boundary
- No fallback behaviour
- No structured output
- No escalation rules

## After

The revised prompt:

- Defines the assistant's role
- Establishes trusted context
- Defines explicit behavioural constraints
- Specifies output schema
- Defines escalation conditions
- Prevents unsupported claims

## Key Lesson

Prompt quality is less about making instructions longer and more about making the model's operating boundaries explicit.
